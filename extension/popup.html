Setup & help

To review a document you need the local runner (install instructions):

  1. Get the runner and open a terminal in the project.
  2. Run node runner/index.mjs <your-docs-dir> — or redline serve — and the first run walks you through setup.
  3. Set OPENROUTER_API_KEY in the environment (or agent.apiKey in redline.config.json). Without it the runner serves and comments work, but no run can reach the agent.
  4. Open http://127.0.0.1:5175/<page>.html

For file:// pages, also enable “Allow access to file URLs” for this extension in chrome://extensions.
